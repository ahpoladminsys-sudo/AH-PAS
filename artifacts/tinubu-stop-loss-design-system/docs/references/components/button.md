# Button family

**Source evidence:** `artifacts/stop-loss-app/index.html`, shared `.btn`,
`.btn-primary`, `.btn-secondary`, `.btn-sm`, CRM `button.pri`, and compact
action button styles.

## Contract

- Primary actions use deep navy or the workspace's teal action color with white
  text.
- Secondary actions are white with a quiet border; destructive actions use red
  only when the outcome is blocking or irreversible.
- Compact actions are used inside dense tables, cards, and modal footers.
- Buttons carry a visible icon only when it clarifies the action; the label
  remains the primary affordance.
