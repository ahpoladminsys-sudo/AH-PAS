# Data table family

**Source evidence:** `artifacts/stop-loss-app/index.html`, `.data-table`,
`.table-wrap`, System Log tables, audit rows, and policy detail tables.

## Contract

- Use a quiet tinted header, compact row padding, and clear 1px dividers.
- Align comparable numeric values and use IBM Plex Mono for identifiers, rates,
  timestamps, and other audit-oriented values.
- Keep row actions at the edge and preserve enough whitespace for review notes.
- On narrow screens, allow horizontal scroll rather than collapsing evidence
  into an ambiguous card layout.
