# Form controls family

**Source evidence:** `artifacts/stop-loss-app/index.html`, shared `.form-control`,
`.form-group`, `.form-grid`, `.detail-field`, and review checkbox patterns.

## Contract

- Use Urbanist for controls and labels; labels are compact, semibold, and
  explicit about required fields.
- Preserve a 4px spacing rhythm, with 8px control padding and an 8px base
  radius.
- Use teal focus rings and input borders that are visibly distinct from the
  page surface.
- In evidence workflows, pair a value with its source status and never imply
  that an inferred value is verified.
