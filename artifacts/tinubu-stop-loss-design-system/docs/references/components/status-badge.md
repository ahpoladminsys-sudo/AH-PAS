# Status badge family

**Source evidence:** `artifacts/stop-loss-app/index.html`, `.badge`,
`.badge-issued`, `.badge-draft`, `.badge-gold`, `.b-mint`, `.b-amber`, `.b-red`,
and `.b-gray`.

## Contract

- Badges are compact, pill-shaped, and used for state or category—not long
  sentences.
- Mint means cleared or healthy, gold means review or pending decision, navy
  means informational or issued, and red means blocked, failed, or destructive.
- Pair color with text or an icon so status remains understandable without
  color perception.
