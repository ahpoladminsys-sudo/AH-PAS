Exercise all integration boundaries — Test the hosted same-origin flow and the downloaded-file flow with a configured API origin and short-lived portable session. Rebuild and validate the distributable HTML — Use the approved controlled rebuild path and latest source inputs, then inspect the generated artifact for current freshness, complete HTML structure, valid inline scripts, absent required local asset references, correct API-origin configuration, and preserved initialization order. Verify the catalog metadata, attachment headers, download contents, and served export all refer to the same build, including the failure/atomic-handoff behavior when a rebuild or source check fails.
Automate the final regression matrix — Extend the existing app-level and API-level fixtures with assertions for the QA transaction journey, persistence round trips, hosted/portable request routing, auth and provider failure states, Sheets read-only truthfulness, Drive sharing boundaries, rebuild freshness, and concurrent export requests. Repair, rerun, and publish the final state — Fix defects found in the transaction or integration matrix within the owning source area, rerun affected checks and the full matrix, then perform one final controlled rebuild.
